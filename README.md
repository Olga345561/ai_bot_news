# AI Bot News

**AI Bot News** — це backend-застосунок для автоматизованого збору новин із вебсайтів і Telegram-каналів, обробки новин за допомогою штучного інтелекту та підготовки дописів для публікації в Telegram.

Проєкт створений у межах навчального модуля з Python Backend Development.

## Можливості

- Збір новин із вебсайтів.
- Отримання повідомлень із Telegram-каналів за допомогою Telethon.
- Збереження новин та інформації про джерела в базі даних SQLite.
- Перевірка новин на дублікати.
- Фільтрація новин за ключовими словами.
- Генерація коротких україномовних Telegram-дописів за допомогою OpenAI API.
- Фонова обробка завдань за допомогою Celery.
- Використання Redis як брокера завдань.
- Публікація підготовлених дописів у Telegram.
- Логування роботи застосунку та помилок.
- Автоматизоване тестування за допомогою pytest.

## Архітектура проєкту

Основні частини застосунку:

- `app/ai/` — інтеграція з OpenAI та генерація дописів.
- `app/news_parser/` — парсинг новин із вебсайтів і Telegram.
- `app/telegram/` — робота з Telegram та публікація дописів.
- `app/` — моделі бази даних, CRUD-операції, допоміжні функції та завдання.
- `tests/` — автоматизовані тести.
- `alembic/` — міграції бази даних.
- `main.py` — точка входу FastAPI.
- `celery_worker.py` — конфігурація Celery.

## Встановлення та запуск

### 1. Клонування репозиторію

```bash
git clone <repository-url>
cd ai_bot_news
```

### 2. Створення віртуального середовища

```bash
python -m venv .venv
```

Активація у Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 3. Встановлення залежностей

```bash
pip install -r requirements.txt
```

### 4. Налаштування змінних середовища

Створіть файл `.env` у корені проєкту та додайте необхідні ключі доступу.

Для роботи застосунку потрібні облікові дані відповідних сервісів:
- OpenAI API;
- Telegram API;
- Telegram Bot API (якщо використовується бот).

**Важливо:** назви змінних середовища мають відповідати тим, які використовуються у конфігурації проєкту. Не додавайте реальні API-ключі до репозиторію.

### 5. Запуск Redis

Redis використовується Celery для передачі завдань між застосунком і фоновими працівниками.

Якщо контейнер уже створений:

```bash
docker start ai-bot-redis
```

Переконайтеся, що Redis доступний на порту `6379`.

### 6. Запуск FastAPI

```bash
uvicorn main:app --reload
```

Після запуску застосунок буде доступний за адресою:

`http://127.0.0.1:8000`

Документація API Swagger:

`http://127.0.0.1:8000/docs`

### 7. Запуск Celery Worker

В окремому терміналі, з активованим віртуальним середовищем:

```bash
celery -A celery_worker:celery_app worker --pool=solo --loglevel=info
```

## База даних

Проєкт використовує SQLite. Файл бази даних:

`ai_bot_news.db`

Для керування структурою бази даних використовується Alembic.

Застосування міграцій:

```bash
alembic upgrade head
```

## Тестування

Для запуску всіх автоматизованих тестів виконайте:

```bash
pytest -v
```

Для запуску тестів окремого модуля:

```bash
pytest tests/test_tasks.py -v
```

## Логування

Застосунок використовує модуль `logging` для фіксації важливих подій, успішного виконання операцій та помилок.

Логи застосунку зберігаються у файлі:

`logs/app.log`

## Безпека

- Не зберігайте API-ключі та паролі безпосередньо в коді.
- Використовуйте файл `.env` для конфіденційних налаштувань.
- Не додавайте `.env`, файли сесій Telegram та локальну базу даних до публічного репозиторію.
- Додавайте конфігураційний файл `.env.example` без реальних секретів.
